# プロジェクト・タスク管理 📋✨

Googleスプレッドシートをデータベースとして活用し、快適で洗練されたUIからプロジェクトおよびタスクを一元管理できるWebアプリケーションです。

---

## 🌟 特徴
- **Googleの警告バーなし**: GitHub Pages等の外部ホスティングで動作し、全画面で美しく表示されます。
- **SWR（高速ローディング）**: ローカルキャッシュにより、開いた瞬間に前回データが待ち時間ゼロで表示され、裏でスプレッドシートと自動同期します。
- **洗練されたダークテーマ**: 目に優しくモダンなグラスモーフィズムデザイン。
- **直感的な操作性**:
  - スマートな自動整列（開始時間順 ＞ 優先度コンテキスト順。スマホのスクロールを妨げない快適設計）
  - タブ切り替え（「すべて」「Biz」「Private」/「期日順」「日付指定」「プロジェクト別」）
  - 柔軟なリピート設定（なし、コピー、毎日、毎週、隔週、毎月）
  - カレンダー・Outlook連携対応
- **1ファイル完結型フロントエンド**: HTML + CSS + JavaScript の軽量構成。

---

## 📁 ファイル構成
- `index.html`: Webアプリ本体（フロントエンド）
- `Code.gs`: Google Apps Script（スプレッドシート連携バックエンド Web API）
- `appsscript.json`: GASプロジェクト設定マニフェスト
- `.clasp.json`: clasp（GAS同期ツール）設定ファイル（※.gitignore対象）
- `README.md`: 本説明書

## 🚀 セットアップ・同期手順

### スプレッドシート（GAS）への反映方法
以下のいずれかの方法で更新を反映できます。

- **方法A（claspを使う場合・推奨）**:
  ターミナルで本フォルダに移動し、以下を実行します：
  ```bash
  clasp push
  ```
- **方法B（手動コピペの場合）**:
  1. 現在お使いのタスク管理用Googleスプレッドシートを開きます。
  2. 上部メニューの **「拡張機能」>「Apps Script」** を開きます。
  3. 本フォルダの `Code.gs` の内容をコピーし、エディタに貼り付けて保存（Ctrl+S）します。

※GAS側の関数やAPI構造を大きく変更した場合は、GASエディタ右上の **「デプロイ」>「デプロイを管理」** から新バージョンのデプロイを行ってください。

### ステップ2: Webアプリ（index.html）でのURL設定
1. `index.html` をブラウザで直接開くか、GitHub Pagesで開きます。
2. 画面右上の **⚙️（設定）アイコン** をクリックします。
3. 「GAS ウェブアプリURL」の入力欄に、ステップ1でコピーしたURLを貼り付けます。
4. **「接続テスト」** をクリックして緑色の成功メッセージが出たら、**「保存する」** をクリックします。
5. これでスプレッドシートと完全同期されたWebアプリとして利用可能になります！

## 🌐 GitHub Pages への公開方法
1. GitHub上に新しいリポジトリ（例: `smart-task-app`）を作成します。
2. 本プロジェクトのファイルをコミット＆プッシュします：
   ```bash
   git add -A
   git commit -m "feat: 初回リリース"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/smart-task-app.git
   git push -u origin main
   ```
3. GitHubのリポジトリ画面で **「Settings」>「Pages」** を開きます。
4. **Build and deployment** の Source を `Deploy from a branch` にし、Branch を `main` / `/(root)` に設定して「Save」をクリックします。
5. 数分後に公開URL（`https://<ユーザー名>.github.io/smart-task-app/`）が発行されます。スマホやPCのブラウザからいつでもアクセス可能です！
